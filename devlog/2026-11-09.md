## Problems and solutions

- **Spiky wide trails.** A projected direction could collapse when the emitter jittered or reversed. The fallback
  then used the current segment, so the same endpoint could have different corners in its two neighbouring
  segments. A near-zero world chord also bypassed the facing fade with full visibility. The new frame depends only
  on the endpoint, looks along a bounded width-sized span, fades a degenerate chord, and closes the inside edge
  before it folds across a sharp turn.
- **Offscreen frame-rate controls.** `max_frame_rate` limits onscreen refresh callbacks only. A scripted/capture
  frame advances by `AppDesc::fixedStep` outside a perf region; a perf region uses uncapped wall-clock time.
  Existing flags cannot vary deterministic render intervals independently of the physics step. A run requesting
  30 Hz offscreen therefore does not establish a 30 Hz animation check.
- **Vulkan demo fixture retry.** `VUID-vkCmdDraw-None-09600` recurred after the Weather capture, before Particles:
  `render cloud layer noise` remained in `TRANSFER_SRC_OPTIMAL` when shader sampling required
  `SHADER_READ_ONLY_OPTIMAL`. The previous release documents an intermittent validation error of this class. The
  cause is unresolved. An independent source audit suggested SDL texture defragmentation as a possible cause,
  not a demonstrated one; no fix for that issue is included here.
