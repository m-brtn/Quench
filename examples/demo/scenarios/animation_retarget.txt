# Animation, retargeting (ctest: demo_animation_retarget_<backend>, a part of batch.txt): the mannequin and the
# strider (other joint names, proportions and rest pose; its clips are the mannequin's retargeted at cook time) walk
# the same clip on circles 1.15 times as wide as each other, abreast, the camera following them. The capture shows
# the two 248 frames after the restart (a camera cut), looking away from the hero's stage. The waits end half a frame
# away from a step of the fixed clock, so that they take the same number of frames wherever the batch's app time is
# (a wait of a whole number of steps can take one more): the pair moves in every frame.
section animation

set dither 0
until anim_ready == 1 3
expect anim_failed == 0
set crowd 0
set view retarget
set restart 1
wait 0.054
expect anim_characters == 8
until anim_bound == 8 1
until anim_ready == 1 3
wait 2.004
expect pair_gap > -1
expect pair_gap < 1
expect pair_height_ratio > 1.14
expect pair_height_ratio < 1.16
windows off
capture demo_animation_retarget.png
windows on

set view hero
set crowd 48
until anim_ready == 1 3
quit
